## Главные ограничения (нарушение = переписать)

- Голос только «я». Никаких «мы», «команда», «студия», «агентство», «без посредников», «без агентского процента».
- Длинное тире «—» запрещено. Только запятая, двоеточие, точка, скобки; для диапазонов короткое «–».
- **Вадим не занимается промышленным дизайном продукта** (проектированием изделий и корпусов оборудования).
  Он делает графический дизайн, сайты, 3D-визуализацию уже спроектированных изделий, упаковку, презентации.
  Не называть его «индустриальным» или «промышленным дизайнером».
- Цены только из _FORMAT.md §4. Для полиграфии, упаковки, этикеток, презентаций, инфографики, моушна,
  нейминга, ребрендинга: «стоимость считаю после брифа». Не придумывать цены, сроки, проценты, число клиентов.
- Калькулятор: ссылка `/#calculator` (отдельной страницы /calculator/ нет). Бриф `/brief/`, контакты `/contact/`.
- Клиентов называть только тех, что есть на живых страницах портфолио и в `reviews.md`, и только с теми
  фактами, что там написаны. Отдельных страниц кейсов нет: ссылайся на страницы портфолио по разделам
  (`/portfolio/branding/`, `/portfolio/web/`, `/portfolio/3d/`, `/portfolio/complex/`, `/portfolio/catalogs/`).
  Портфолио упаковки пока нет: для упаковки и этикеток примеры «покажу по запросу», без ссылки.
- Внешних ссылок нет. Внутренние только на URL из списка ниже.
- Тематическая страница (помечена «тема» ниже) короче обычной: 600–1000 слов, но всё равно с `:::faq`
  (3–5 вопросов), `:::steps` или `:::cards`, ссылкой на родительскую страницу, на портфолио, на `/#calculator`
  или `/brief/`, и финальным `:::cta`. Обычная страница услуги 900–1500 слов, хаб 500–1000.
- Каждая страница должна отличаться от соседних: свой угол, свои вопросы в FAQ, без копирования абзацев
  с родительской страницы. Тематическая страница раскрывает узкий запрос (например, «отрисовка логотипа цена»:
  из чего складывается работа, какие исходники подходят, что получите на выходе).
- Ключевые фразы страницы вписывать естественно в title, h1, lead, 1–2 подзаголовка и текст. Без переспама.
- Title 45–65 знаков, заканчивается на « | Вадим Паршуков». Description 140–170 знаков.
- `related:` 3–6 URL из списка ниже (не `/#calculator`).
- Хаб раздела обязан ссылаться блоком `:::links` на все свои дочерние страницы из списка ниже.

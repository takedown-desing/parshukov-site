Дизайн-система та же, что в V1 и V2 (`shared/css/site.css`, `v2.css`). Новые блоки описаны в `shared/css/v3.css`.

## Порядок блоков

Шапка (5 пунктов: Обо мне, Услуги, Отрасли, Кейсы, Контакты) → первый экран → обо мне → цифры → услуги (4 с ценами + 3 компактные) → отрасли → три флагманских кейса → лента работ → клиенты → рекомендации → FAQ (7 вопросов) → форма с плашками «калькулятор» и «мессенджеры» → призыв → подвал (5 колонок).

## Внутренние страницы (сборка 29.10.2026)

Все 77 страниц из дерева сайта (`tools/pages.py`) собираются скриптом:

```bash
python3 tools/check_content.py   # проверка текстов: тире, запрещённые слова, цены, ссылки
python3 tools/build_v3.py        # страницы v3/<url>/index.html, v3/sitemap.xml, шапка и подвал главной
```

- Тексты лежат в `content/v3/<slug>.md`, формат описан в `content/v3/_FORMAT.md`. Править тексты нужно там, а не в HTML: HTML перезаписывается при сборке.
- Стили страниц: `shared/css/v3-pages.css`. Скрипты: `shared/js/v3-pages.js` (меню «Услуги», оглавление статей) и `shared/js/calculator.js`. Файлы V1, V2, `site.css`, `v2.css`, `site.js` не менялись.
- SEO на каждой странице: title, description, canonical, Open Graph, хлебные крошки, JSON-LD (BreadcrumbList; Service, BlogPosting, CreativeWork, CollectionPage, AboutPage, ContactPage по типу страницы; FAQPage, если есть вопросы), один H1, внутренняя перелинковка «Смотрите также».
- Карта сайта: HTML `/sitemap/` (ссылка в подвале каждой страницы) и `v3/sitemap.xml` для поисковиков. Адреса в XML указаны на GitHub Pages, при переезде на домен нужно поменять `SITE_URL` в `build_v3.py` и пересобрать.
- На всех страницах оставлен `noindex, nofollow`: это прототип. Снять перед запуском на домене.
- Страница 404 собрана как `v3/404/index.html`. GitHub Pages показывает только корневой `404.html`, а корень сайта общий для трёх вариантов, поэтому он не тронут. На домене нужно отдать эту страницу как 404.
- Политика конфиденциальности и пользовательское соглашение помечены как черновики: их нужно согласовать с юристом.
- Исключения проверки текстов: слова «студия» и «агентство» в статье `/blog/dizayn-studiya-obzor/` (статья про выбор между студией и частным дизайнером), «Лучшие» в заголовке `/blog/luchshie-sayty-na-tilde/` (так звучит запрос).

## Калькулятор

Свёрстан по макету «Калькулятор» (`данные по запуску сайта/Main Page*.pdf`) и тексту `Калькулятор.docx`. Стоит на главной сразу после трёх главных кейсов (перенесён 30.10, раньше стоял перед формой) и на странице `/calculator/`.

- Три шага: фирменный стиль, сайт, 3D. В каждом шаге есть вариант «не нужно», без выбора дальше не пускает. Четвёртый экран: форма онлайн-встречи (телефон, почта, мессенджер, согласие). «Назначить встречу» открывает его сразу.
- Цены и сроки вариантов задаются в `CALC_STEPS` в `tools/build_v3.py`.
- Оплата: сумма меньше 60 000 ₽: 100% предоплата, скидка недоступна (строка бледнеет). От 60 000 ₽: 50% предоплата, при выборе скидки сумма уменьшается на 20%, предоплата 80%.
- Срок: допущение, в макете формулы нет. Берётся самая долгая выбранная услуга и добавляется по полнедели за каждую следующую, потому что работы частично идут параллельно. Нужно подтвердить у Вадима.
- Исправлены опечатки макета: «Выберете» → «Выберите», «в ручную» → «вручную», «МВП» → «MVP», «не больших» → «небольших».
- Форма калькулятора и остальные формы пока не подключены к серверу (`data-endpoint=""`): при отправке человек видит ссылки на Telegram и WhatsApp. В заявку калькулятора уходят выбранные услуги, сумма, срок и условия оплаты.

# Сайт Вадима Паршукова: три прототипа

Статическая вёрстка (HTML, CSS, vanilla JS) личного сайта Вадима Паршукова, B2B-дизайнера для производственных и экспортных компаний. Одна дизайн-система, три версии содержания. Все версии адаптированы под мобильные (точки перелома 1440, 1100, 640 px).

| Версия | Папка | Что это |
|---|---|---|
| V1 | [`v1/`](v1/index.html) | Точная вёрстка макета из Figma (холст 1920 px, контейнер 1200 px) |
| V2 | [`v2/`](v2/index.html) | Макет плюс правки Вадима из видеоразбора |
| V3 | [`v3/`](v3/index.html) | Тот же дизайн, структура и тексты главной по SEO-стратегии продвижения |

Стартовая страница с выбором версии: [`index.html`](index.html).

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```

Сборки нет, зависимостей нет.

## Структура

```
shared/
  fonts/   Unbounded (заголовки), Montserrat (текст), woff
  css/     site.css: токены, компоненты, адаптив; v2.css: FAQ-аккордеон, анимация карточек, внутренние страницы
  js/      site.js: мобильное меню, анимация карточек у формы, проверка формы
  img/     изображения из макета, webp
v1/  v2/  v3/
```

Палитра: синий `#0369B7` (акценты `#217BBF`, `#2B69B2`), графит `#1F1F1F`, чёрный, серые `#F5F5F5`–`#898989`. Кнопки при наведении инвертируются (белый ↔ чёрный/графит), как просил Вадим.

## Что Вадим сказал в видео (только про сайт)

- В меню пока четыре раздела: обо мне, услуги, кейсы, контакты.
- «Обсудить проект» и «Связаться» ведут к форме внизу. В шапке ссылки на Telegram, WhatsApp, MAX.
- Кнопку «Рассчитать проект» пока переименовать в «Заказать проект»: калькулятор будет позже, ТЗ на него готово.
- В услугах «Смотреть кейсы» ведёт на отдельную страницу кейсов. Цены в макете действуют 4 месяца.
- Рекомендательные письма: на сайте 4, остальные по ссылке на Яндекс.Диск, без каруселей.
- FAQ: кнопку «Смотреть все частые вопросы» убрать, вопросы раскрываются, ответы в `FAQ_ответы_для_разработчика.docx`.
- Команда остаётся как есть, без расширения.
- Форма: бюджет и удобный способ связи (Telegram, WhatsApp, MAX). Почту как канал связи не ставить.
- Анимаций минимум: инверсия кнопок при наведении и «вылет» двух боковых карточек из центральной над формой.
- Дальше: мобильная версия по его макету, калькулятор, внутренние страницы кейсов, рабочая отправка формы, затем англоязычная версия.

## Изменения V2 относительно макета

- «Рассчитать проект» → «Заказать проект».
- «Кейсы» в меню, футере и кнопки «Смотреть кейсы» ведут на `v2/cases.html` (заготовка сетки работ).
- FAQ стал аккордеоном `<details>` с ответами из документа Вадима, кнопка «Смотреть все» убрана.
- Боковые карточки над формой вылетают из центральной при прокрутке (учтён `prefers-reduced-motion`).
- Убрана ссылка на e-mail в футере. Политика конфиденциальности вынесена в `v2/privacy.html` (черновик на основе `Защита.docx`, нужна проверка юристом).
- Исправлена формулировка про срок цен: «действуют в течение 4 месяцев, до февраля 2027 года».
- Форма: честная проверка телефона, согласие не отмечено заранее, скрытое поле от ботов.

## Форма заявки: что нужно до запуска

Сейчас форма проверяет поля в браузере и, если сервер не подключён (`data-endpoint` пустой), предлагает написать в Telegram или WhatsApp. Для боевого запуска:

1. Обработчик на сервере (например, Cloudflare Pages Functions): POST JSON, отправка в Telegram-бота или на почту.
2. Повторная проверка всех полей на сервере, ограничение длины, отказ при заполненном скрытом поле `website`.
3. Защита от спама: Cloudflare Turnstile, ограничение частоты запросов.
4. Заголовки безопасности по `Защита.docx`: HTTPS и HSTS, CSP, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`.
5. Ключи и токены только в переменных окружения хостинга, не в репозитории.
6. Хранение персональных данных по 152-ФЗ: сервер в РФ или согласие на трансграничную передачу.

## Открытые вопросы

- **Тексты и правила контента.** В макете есть блок «Команда» и формулировки про «агентские наценки». Это расходится с принципами контента проекта (личный бренд, голос одного эксперта). V1 и V2 повторяют макет и видео, V3 следует принципам стратегии.
- Почта для заявок и футера не указана, по видео её и не нужно показывать.
- Домен и хостинг не выбраны. Для .ru нужна регистрация с подтверждением личности.
- Калькулятор, внутренние страницы кейсов, мобильный макет от Вадима ожидаются отдельно.
